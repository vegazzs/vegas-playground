# Simple Counter — A Beginner-Friendly Practice Project

A clean, minimal counter app built as part of **The Vegas Playground Projects** — a series of small, beginner-friendly builds designed to give new developers something real to practice on.

This isn't meant to be a complex or "impressive" project — it's meant to be **simple enough to fully understand**, so beginners can clone it, read through the whole codebase in a few minutes, and start experimenting without feeling overwhelmed.

![Simple Counter Preview](/assets/review.png)

## Who This Is For

- Beginners learning JavaScript fundamentals who want a small, real project to practice on
- Developers who want a simple sandbox to experiment with new features without breaking anything complex

## Features

- Increment (`+`) and decrement (`−`) the counter with a click
- Keyboard support — arrow keys to increment/decrement, Enter to reset
- Reset the counter back to zero at any time
- Smooth animation when the count changes
- Smooth gradient display panel for the current count
- Simple, responsive, and dependency-free — pure HTML, CSS, and JavaScript

## Tech Stack

- **HTML** — structure
- **CSS** — styling and gradient design
- **JavaScript** — counter logic and DOM interaction

No frameworks, no build tools, no dependencies — intentionally kept simple so anyone at any level can read and understand the whole project quickly.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/simple-counter.git
   ```
2. Open `index.html` in your browser.

That's it — the counter runs entirely client-side, nothing to install or configure.
